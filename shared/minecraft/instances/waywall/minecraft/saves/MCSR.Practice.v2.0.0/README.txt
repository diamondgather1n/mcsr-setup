Installation:

1. Unzip the file
   I recommend WinRAR or 7zip to avoid file issues
2. Open the unzipped folder and verify the structure
   There must be no folder inside another folder. If there is, drag the inner folder out
3. Move the map folder into the saves folder of your Minecraft instance.
4. Start Minecraft and select the world
   Start Practicing :)

If you break a sign in the hub, block etc you can use "/trigger repairhub" to fully repair the hub
